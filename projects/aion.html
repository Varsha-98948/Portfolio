Meet Aion

A local-first personal operating system for thoughts, memories, tasks, and projects — designed to bring your context back when you need it.

StatusIn Development
PlatformWeb
Year2026
RoleSolo Builder
Think of Aion as a second brain—a calmer operating system for everything you don't want to lose.

Why I’m Building It

Important context — ideas, tasks, memories, project threads — gets scattered across notes, chats, and reminders. I wanted a single place where that context could resurface exactly when it's useful, instead of disappearing into fragmented tools.

What Makes It Different

Aion isn't a notes app or a to-do list bolted onto a chatbot. It's built around intent matching and local-first context, so it can understand what you're asking for and surface the right memory, task, or project detail without relying on external APIs.

Challenges

  • Learning AI fundamentals while designing a real product
  • Keeping the scope believable at a portfolio stage
  • Designing intent matching without external APIs
  • Structuring memory so context stays retrievable, not just stored
  • Balancing assistant behavior with restraint over spectacle
  • Building an interface that feels calm rather than like a chatbot

Lessons Learned

  • Good assistants need context and trust more than clever responses
  • Local-first constraints force clearer architecture
  • Memory is only useful if it's structured for retrieval
  • Restraint is a feature, not a limitation
  • Scope discipline matters as much as ambition

Key Features

What Aion Does

The core capabilities Aion is being built around, from context memory to a live assistant already on this site.

Local-First Intelligence

Aion runs its intent matching locally, without relying on third-party AI APIs, keeping the assistant fast and self-contained within the portfolio.

Context Memory

Designed to hold onto ideas, notes, and project threads so they can resurface later, instead of getting lost across scattered tools.

Task & Project Awareness

Structured around real work in progress — tasks, deadlines, and project state — not just freeform notes.
