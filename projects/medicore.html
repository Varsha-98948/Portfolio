Project Showcase

MediCore

A web-based hospital management platform designed to organize healthcare operations with flexible data handling and an intuitive interface for managing records.

StatusCompleted
PlatformWeb
Year2026
RoleFull-Stack
Think of MediCore as a way to make healthcare data easier to manage—flexible enough for different records while still keeping information organized and accessible.

Why I Built It

I wanted to explore how healthcare systems handle different types of data and whether a flexible NoSQL approach could still provide the structure developers and users expect from traditional databases.

What Makes It Different

MediCore combines flexible document-based storage with a SQL-like query interface. This allowed me to experiment with storing varied healthcare records while still making it easier to search, filter, and understand the data.

Challenges

  • Designing a flexible data structure for different healthcare records
  • Building a query system that converts simple commands into database operations
  • Managing different modules like patients, billing, and inventory together
  • Keeping data consistent across multiple parts of the application
  • Creating an interface that makes complex data easier to understand
  • Balancing flexibility of NoSQL storage with structured data access

Lessons Learned

  • Choosing the right data structure has a major impact on application design
  • Flexible storage still needs clear ways to access and understand information
  • Building multiple connected modules requires careful planning from the start
  • Good interfaces can make complex systems easier for people to use
  • Backend decisions directly influence the overall user experience

Key Features

What MediCore Does

Four operational modules that keep hospital data flexible, searchable, and current.

Patient Management

Register admissions, check bed occupancies, log clinical vitals, and manage patient profiles from a single unified directory.

SQL-Like Query Console

Perform structured, familiar queries over loose NoSQL document records—with syntax autocomplete and export to Excel, PDF, or CSV.

Operations Desk

Track ward occupancy in real time, manage on-call staff rosters, and monitor medical inventory with automatic low-stock alerts.

Billing & Discharge

Run automated discharge checklists, itemize stay and pharmacy charges, and validate insurance claims before submission.
