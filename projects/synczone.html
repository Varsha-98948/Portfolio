SyncZone

<

An Android campus communication app built to bring students and teachers together through real-time collaboration while maintaining a professional, curse-free environment.

StatusCompleted
PlatformAndroid
Year2025
RoleFull-Stack Developer
Think of SyncZone as Discord meets Google Classroom—designed exclusively for educational institutions.

Why I Built It

Educational communication often lives across WhatsApp groups, emails, classroom notices, and shared drives. I wanted to create one platform where students and teachers could collaborate professionally without distractions, scattered information, or inappropriate communication.

What Makes It Different

Unlike traditional classroom messaging platforms, every message is checked using a real-time profanity detection API before it reaches other users. This creates a safer, distraction-free environment where discussions remain focused on learning.

Challenges

  • Building my first large-scale Android application
  • Learning Firebase architecture from scratch
  • Designing separate Teacher & Student workflows
  • Integrating real-time chat and live synchronization
  • Implementing profanity detection without affecting UX
  • Enabling two-factor authentication for secure login

Lessons Learned

  • Plan the architecture before writing code
  • Design scalable database structures
  • Break complex features into smaller milestones
  • Debugging is as important as development
  • Great products solve user problems, not just technical ones

Key Features

What SyncZone Does

The key features I built to bring classroom communication, collaboration, and a more respectful online environment into one place.

Real-Time Messaging

Firebase and Supabase-powered chat that keeps conversations updated instantly across users. Building real-time communication helped me understand how live data synchronization works in a practical application.

Profanity Filtering

Messages are checked using the Purgomalum API before being sent, automatically replacing inappropriate words with symbols. This was built to maintain a more professional and comfortable space for student-teacher communication.

Student & Teacher Roles

Separate interfaces for students and teachers with role-specific features. Teachers can share announcements and assignments, while students get a simpler space focused on communication and learning.

Assignment Management

A dedicated space for creating, sharing, and tracking assignments without switching between different platforms. It keeps classroom tasks, deadlines, and updates organized in one place.
