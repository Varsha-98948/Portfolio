GreenGrid

A developer productivity platform for tracking DSA problem-solving progress—GitHub-authenticated, dashboard-driven, and built to keep your streak alive.

StatusCompleted
PlatformWeb
Year2025
RoleFull-Stack
Think of GreenGrid as GitHub meets a LeetCode tracker—built to make consistent practice visible.

Why I Built It

Practice problems end up scattered across spreadsheets, browser bookmarks, and half-finished notebooks. I wanted one place tied to a developer's actual GitHub identity where solved problems, streaks, and topic coverage are always visible at a glance.

What Makes It Different

Sign-in runs entirely through GitHub OAuth, so there's no separate account to manage. A short onboarding flow tailors the dashboard to your goals, and every problem you log feeds a live streak and progress view instead of a static list.

Challenges

  • Designing a REST API in Spring Boot from the ground up
  • Wiring GitHub OAuth into both frontend and backend
  • Modeling progress and streak data in PostgreSQL
  • Building fast search and filtering across problem sets
  • Containerizing the backend for consistent deploys
  • Coordinating separate deploys across GitHub Pages and Render

Lessons Learned

  • Design the API contract before the UI that consumes it
  • OAuth flows need careful handling of edge cases and errors
  • A good onboarding step pays for itself in retention
  • Docker makes environment drift someone else's problem
  • Dashboards should surface trends, not just raw counts

Key Features

What GreenGrid Does

The core capabilities that turn scattered practice into a visible, consistent habit.

DSA Progress Tracking

Log every problem you solve and watch topic-wise coverage build over time. Progress is grouped by difficulty and category so gaps in practice are easy to spot.

GitHub OAuth Authentication

Sign in with an existing GitHub account—no new password to create or remember. Authentication is handled securely end-to-end between the frontend and the Spring Boot API.

Personalized Onboarding

A short setup flow captures goals and experience level right after sign-in, so the dashboard reflects what each developer is actually working toward from day one.

Problem Management

Add problems manually with tags, difficulty, and notes, and pull them back up instantly whenever they're needed for a review session.

Powerful Search & Filtering

Find any logged problem instantly by name, tag, difficulty, or status. Filters narrow the list in real time without reloading the page.

Streak Tracking & Analytics

A live dashboard surfaces daily streaks, solved counts, and trend lines, backed by a Dockerized Spring Boot API and a PostgreSQL data layer built for consistent, secure updates.
